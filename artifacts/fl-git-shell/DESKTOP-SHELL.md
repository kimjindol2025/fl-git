# fl-git 데스크톱 셸 계약

1단계는 기능 이전이 아니라 화면 뼈대 고정이다.

## 화면 계약

- 대상 폭: 1200px 이상, 기준 화면 1440px
- 모바일 레이아웃: 제공하지 않는다.
- 열: `300px 고정 좌측 / 유동 중앙 / 300px 우측`
- 좌측: 서버에서 관리 가능한 Git 저장소 목록 자리
- 상단: `root`, `branch`, `upstream`, `ahead/behind`
- 중앙: 이후 변경 파일·Diff·커밋 화면 자리
- 우측: 선택 항목 상세 자리, 접으면 중앙이 넓어진다.
- PR·Actions·Issues는 이 셸 범위에 포함하지 않는다.

## 상태 전이

`right-open=true`이면 우측 상세 패널을 표시한다.

`right-open=false`이면 우측 패널을 52px로 접고 중앙 열이 남은 공간을 사용한다.

1단계에서는 기존 기능을 셸 안으로 재배치하지 않는다. 다음 단계에서 좌측 저장소 선택을 먼저 구현한다.
