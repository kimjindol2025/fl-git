# FE-18: 서버 데이터와 Island 연결

## 전달 계약

서버는 데이터를 JSON으로 직렬화해 `type="application/json"`인 페이지 내 스크립트 노드에 넣는다. 이 노드는 실행되지 않는 데이터 블록이다. HTML의 raw-text 안에서 태그로 해석될 수 있는 `<`, `>`, `&`는 JSON 문자열에서 각각 `\u003c`, `\u003e`, `\u0026`로 바꾼다. Island는 노드를 찾아 `textContent`를 `JSON.parse`해 값을 복원한다. 복원 값은 DOM 텍스트 API로 출력하므로 상품 이름이 HTML로 해석되지 않는다.

FE-15 검사기가 정의한 Island 선언 모양을 유지한다. 선언의 두 번째 인자 `[]`는 props 인자가 아니라 옵션 모양이며, 서버 값을 선언에 직접 삽입하지 않는다. 데이터 노드와 Island 사이를 페이지별 ID로 연결한다. JSON escape는 파싱 뒤 원래 문자로 되돌아가므로 UTF-8 직렬화 바이트가 서버 데이터와 복원 데이터에서 같다.

## 적용 범위

- 상품 목록 서버 페이지는 `fl-products-load` 결과를 안전한 JSON으로 넣고 기존 서버 렌더링 카드와 함께 제공한다. `ProductList` Island는 같은 상품 배열을 복원해 개수를 표시한다.
- 장바구니 서버 페이지는 `fl-cart-summary` 전체를 넣는다. `CartPage` Island가 항목과 합계를 복원해 표시한다.
- 생성기(`tools/flp-compile.fl`)는 페이지 렌더 함수와 Island 선언을 각각 `web/pages/`와 `web/islands/`에 쓴다. `cart.flx`와 `index.flx`도 서버 라우트와 브라우저 Island 코드가 섞이지 않도록 같은 분리 원칙을 적용했다. Island 본문은 삭제하거나 빈 함수로 대체하지 않았다.
- 장바구니 요약은 각 상품을 명시적인 함수 호출 람다로 변환해, 시험용 파일 데이터로 세 줄과 합계 164000원을 계산한다.

## FX 필요

TUI의 종료 정리 경로가 호출하는 `tty-raw-leave!`를 FX에서 제공해야 한다. Native 행렬의 남은 한 항목을 채우려면 해당 FX 기능이 필요하다. 이번 작업은 FX 저장소를 변경하지 않았다.

검증은 지정된 저장소 worktree에서 수행했다. 데이터베이스 연결이나 주문 저장 없이 파일 기반 시험 데이터를 사용했으며, 앱 서버를 시작하지 않았다. 검사 스크립트와 기준값은 수정하지 않았다.
