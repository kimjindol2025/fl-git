기준은 `fix/shop-session-orders`의 FE-18 기반 미커밋 수정이다. 2026-11-17 결과는 `SHOP-SECURITY-2026-11-17.md`에 보존한다. 원래 FE-17 작업 트리와 운영 데이터는 수정하지 않는다.

## 독립 정적 검수

별도 검증 에이전트가 읽기 전용으로 소스·실행기 의미·시험 범위를 검토했다. 검증자는 파일 수정, 빌드, 동적 시험, 네트워크 접근을 수행하지 않았다.

| 확인한 문제 | 수정 |
|---|---|
| JSON을 쓴 뒤 chmod해 임시 파일이 잠시 읽힐 수 있음 | noclobber와 umask077로 빈 파일을 먼저 만들고, 기본 ACL을 제한하는 chmod600까지 성공한 다음에만 민감 데이터를 쓴다. |
